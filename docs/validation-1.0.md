## Reproduce

```powershell
npm ci --prefix automation --ignore-scripts
npm run check
npm test
npm run test:automation
npm run verify
npm --prefix automation run test:browser
npm run audit:civitai-contract
npm run regression:civitai -- --images 8 --versions 20
npm run regression:model-families
npm run regression:public-images
```

Runtime: Windows, PowerShell **7.6.9**, Node.js **26.13.0**, npm **12.2.1**. HTTPS tooling uses the system certificate store. Live regressions are bounded but their returned public data can change.

## Boundaries

- The portable app remains dependency-free. The API/MCP companion is optional and separately installed; it was not registered in a user's assistant configuration or left running.
- The family test validates labels and canonical round trips, not images generated by every model family. The 8K fixture is synthetic, not a real-world 8K corpus.
- Firefox, Safari, macOS, Linux, the minimum Node.js 24 runtime, and manual screen-reader operation were not tested locally. The CI configuration targets Windows/Linux but was not run remotely for these changes.
- Passing tests and a clean dependency audit are not a security certification or a claim of complete WCAG conformance.
- A current MCP client supporting protocol **2026-07-28** is required. Older initialization-only clients are intentionally rejected.
- Local validation does not itself establish publication. See the [release page](https://github.com/chriscollins500/civitai-metadata-studio/releases/tag/v1.0.0) and [CI history](https://github.com/chriscollins500/civitai-metadata-studio/actions) for remote results.

The [current Civitai Site API documentation](https://developer.civitai.com/site/) was refreshed on 2026-11-14; contract details and primary references are recorded in [the automation guide](automation.md).
