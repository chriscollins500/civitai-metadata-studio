# Civitai Metadata Studio 1.0.1 — Stronger foundations, same simple workflow

**Open an image. Understand its recipe. Save a better copy.**

This maintenance release improves the optional API/MCP tooling and the checks behind every download. The portable editor is still one HTML file: no installer, no account, no image uploads, and no changes to your originals.

## Get started

Download **civitai-metadata-studio.zip**, unzip it, and open **civitai-metadata-studio.html** in a current browser. Or download the standalone HTML directly. Existing users can simply replace their app copy; no image conversion or migration is required.

## What improved

- **More reliable reconnects.** The development MCP client's legacy-SSE transport now retains the server's event cursor when reconnecting, in both ESM and CommonJS. Regression tests cover cursor updates, resets, Unicode, authentication headers, and redirect isolation.
- **Lean, reviewed tooling.** The Node-only MCP launcher uses native Node spawning and a reproducible, integrity-pinned SDK repack. Six unused standalone spawning packages are gone; the dependency tree is reduced from 20 packages to 14. Playwright is unchanged.
- **Current, coordinated dependencies.** The development client's eventsource 5.1.5, eventsource-parser 4.1.3, and pkce-challenge 6.0.0 update together, retaining a single parser. No dependency is added to the browser app.
- **Checks that travel with the source.** Clean installs, SDK reproduction, exact file hashes, transport/OAuth regressions, and Chrome/Edge tests run on Windows and Linux with Node.js 24 and 26.
- **Authenticated downloads.** The HTML, ZIP, and checksum manifest have GitHub/Sigstore build provenance, with verification against the release tag's source commit.

Since 1.0.0, the project also gained a hosted editor entry point, a comprehensive user/developer wiki, community/support guidance, and stronger release infrastructure. See the [changelog](https://github.com/chriscollins500/civitai-metadata-studio/blob/v1.0.1/CHANGELOG.md) for the complete history.

## Browser users and automation users

The browser editing workflow, metadata identity rules, privacy boundaries, and encoded-pixel preservation remain the same. Version reporting is now consistently **1.0.1** across the app, companion, OpenAPI, and documentation.

The SDK/dependency fixes are included in GitHub's **source archives**, not bundled into the portable HTML. For the optional companion, use Node.js 24+ and the [setup guide](https://github.com/chriscollins500/civitai-metadata-studio/blob/v1.0.1/docs/automation.md). Install dependencies with scripts disabled and run `npm run sdk:check`; no patch-install hook is needed.

## Verify your download

The ZIP contains exactly one HTML file, including its MIT license notice. `SHA256SUMS.txt` lists the HTML and ZIP checksums. With a current GitHub CLI:

```powershell
gh attestation verify civitai-metadata-studio.zip --repo chriscollins500/civitai-metadata-studio --signer-workflow chriscollins500/civitai-metadata-studio/.github/workflows/ci.yml --source-ref refs/tags/v1.0.1 --deny-self-hosted-runners
```

Substitute the HTML or checksum filename to verify the other assets. Attestations establish build origin, not a malware-safety guarantee or an operating-system code-signing badge. [Verification details](https://github.com/chriscollins500/civitai-metadata-studio/blob/v1.0.1/docs/provenance.md).

## Validation and exact files

The release is gated by the full Windows/Linux suites on Node.js 24 and 26: **102 core + 117 automation/MCP + 5 site tests**, plus **36 Chrome/Edge checks per configuration**. The final HTML was also opened directly from the extracted ZIP in Chrome and Edge; a synthetic image was edited, saved, reopened, and checked for byte-preserved encoded pixels. These are automated checks, not a claim of real-provider OAuth interoperability or a new live Civitai image-corpus run.
