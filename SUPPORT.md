# A good place to start

You do not need to understand ComfyUI, hashes, or image-generation jargon to ask for help. Tell us what you were trying to do and what happened.

The [project website](https://chriscollins500.github.io/civitai-metadata-studio/) connects the editor, [learning hub and sample](https://chriscollins500.github.io/civitai-metadata-studio/learn/), [verified downloads](https://chriscollins500.github.io/civitai-metadata-studio/downloads/), [privacy boundaries](https://chriscollins500.github.io/civitai-metadata-studio/trust/), and community.

## The most useful details

Include the application version (or exact website page URL); browser/OS or Node/MCP-host versions; image format where relevant; smallest reproducible steps; expected and actual behavior; and safe warning/problem codes. Say whether it happens before verification, after import, or after exporting/reopening. Website navigation/search/theme reports do not require an image.

For workflow detection, identify relevant node classes, switches, enabled states, and the output path. The graph saved inside the image may differ from the workflow currently open in ComfyUI. For identity problems, exact public AIR/version/file IDs and hashes are more useful than similar names.

## Please protect your own information

Public issues and Discussions are visible to everyone. Browser audit reports can contain full prompts and conflict values. Original ComfyUI metadata can contain local paths and private notes. API/MCP prompt omission is not a universal redaction tool.

Use synthetic examples, cropped/redacted screenshots, and minimal graphs where possible. Do not post private images, full workflows, identifying metadata, credentials, cookies, Authorization headers, tokens, or personal paths. Do not upload a model file to request identification; hash it locally if you have permission to read it.

If a private file seems necessary, describe the problem first and wait for a suitable agreed channel. A security advisory is for vulnerabilities, not a general private file-transfer service.

## Expectations

This is a community-maintained project with no guaranteed response time or commercial support SLA. A report is welcome even when you cannot provide a fixture, but complex cases may remain unconfirmed without a safe reproduction. A feature request or roadmap entry is not a promised release date.

Keep original files. Do not disable integrity checks or TLS protections to force a result. A Civitai rate limit requires waiting, not repeatedly pressing Verify or clearing the cache.

## Conduct concerns

See the [community code of conduct](CODE_OF_CONDUCT.md). GitHub's Report content/Report abuse flow can privately notify GitHub about harassment, threats, or exposed personal information; it is not a private maintainer inbox. Never repost harmful/private material merely to explain a moderation concern.
