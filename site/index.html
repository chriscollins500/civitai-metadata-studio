Read the exact privacy boundary →

Small, deliberate network requests

Automatic verification may send exact hashes or version IDs to Civitai. Explicit search sends your query; image import sends a public image ID. Turn off automatic verification and avoid network actions for local-only work.

Preserved pixels, honest metadata

Exports retain supported encoded pixels and animation payloads. Changing width/height changes metadata, not image resolution. A verified resource is not proof of historical use.

Privacy needs your review, too

Original ComfyUI carriers remain unchanged and may contain private notes or paths. Reports can contain prompts. Inspect the saved copy before sharing; this is not a forensic anonymizer.

A few good questions

Before you open your first image.

Do I need to know anything about ComfyUI or Civitai?

No. Start with a supported image. You can read and edit its available metadata without either tool or a Civitai account. The guides explain the jargon as you go.

Can it recover a prompt that was stripped from an image?

Not from pixels alone. Studio reads existing metadata and can import a known public Civitai image's available recipe. It does not visually identify a model or invent missing historical settings.

Does it resize, recompress, or change my picture?

No. It writes new same-format metadata around the supported original encoded payload. Dimension fields are editable metadata. Original ComfyUI graphs stay byte-preserved rather than being rewritten to match your edits.

Can I use it offline or with very large images?

Download the portable HTML for offline inspection, editing, and saving. Civitai reads need internet access. 8K is a design/test target, not an unlimited-memory promise; preview and batch limits depend on your browser and computer.

How do I know the hosted app matches the portable file?

This site copies the committed, verified portable HTML without changing its bytes. Current app: %%APP_VERSION%%. Its SHA-256 is %%APP_SHA256%%. Check the site artifact manifest and release-verification guide. Hosting is not a separate security certification.

Where can I ask for help or suggest an improvement?

Ask in Q&A, use the issue forms for reproducible problems, or explore the roadmap. Review every attachment before posting; use private reporting for vulnerabilities.
