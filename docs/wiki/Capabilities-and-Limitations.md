# A clear boundary is a feature

**Outcome:** decide whether Studio fits your task without treating design goals as verified universal support.

## It does

- Inspect/edit supported PNG, JPEG, and WebP metadata using one portable HTML file.
- Preserve supported encoded image/animation payloads while saving new same-format files.
- Start editable dimensions from actual image facts.
- Expose 16 generation fields and 14 resource roles with provenance/conflicts.
- Resolve exact public identities through AIR/version/hash evidence, with bounded caching/batching.
- Interpret supported active ComfyUI branches rather than listing every canvas resource.
- Import one explicitly selected public Civitai image's available recipe.
- Provide optional local HTTP/MCP automation with roots, revisions, and new-file-only export.
- Ship checksums and keyless build attestations for release artifacts.

## It does not

- Generate images, resize/upscale, convert formats, recompress, or edit visual content.
- Identify a model by visual resemblance or infer exact IDs from names.
- Recover metadata that no longer exists or guarantee every field can be filled.
- Prove historical model use, authorship, permission, consent, or pixel-identical regeneration.
- Rewrite original ComfyUI graphs to match new form values.
- Understand every custom node, unresolved runtime switch, or ambiguous multi-output graph.
- Automatically pair arbitrary JSON sidecars in the browser.
- Edit model tensors, download models, upload media, run cloud generation, or write to Civitai.
- Persist edits/prompts/workflows as an autosaved project.
- Provide universal forensic anonymization or complete manual accessibility certification.
- Claim every browser/OS or real image from every model family has been tested.

## Evidence versus aspiration

| Statement | What it establishes | What it does not establish |
| --- | --- | --- |
| Portable HTML | No app installation/runtime dependency for browser use. | Identical behavior in every browser/profile/filesystem. |
| Synthetic 8192×8192 PNG check | That specific metadata/payload path can handle that fixture. | Unlimited-size previews or exhaustive 8K format coverage. |
| Chrome/Edge browser suite | Tested interactions/artifact in those environments. | Safari, Firefox, macOS/mobile, or every assistive technology. |
| Windows/Linux Node CI | Companion/build/tests on two operating systems. | Browser UI behavior on every OS. |
| 121 normalized family labels | Structural family-label handling. | Generation/reconstruction tests for all those models. |
| Exact identity badge | Compatible catalog/file evidence matched. | Complete truth of embedded image metadata. |
| Payload integrity proof | Protected encoded pixels/frames unchanged. | Unchanged entire file or total privacy erasure. |
| Signed provenance | Download digest bound to expected build identity. | Malware-free, Authenticode-signed, or notarized software. |

## When another tool is needed

Use an image editor for visual changes, a generator for rendering, and a workflow editor for graph rewiring. Use a dedicated reviewed sanitization process if your requirement is complete removal of embedded workflows/private material. Keep the original as the reference artifact.

If an extension would materially change architecture, data transmission, or preservation guarantees, it needs explicit design/review—not a hidden fallback. The goal is a tool whose claims remain trustworthy as its capabilities grow.
