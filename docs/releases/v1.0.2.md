# Civitai Metadata Studio 1.0.2 — Clearer guides, stronger checks

**Your image. Its recipe. A clean new copy.**

This small maintenance release strengthens the checks behind the project: safer wiki heading handling, 14 focused regressions, and a reliable browser rate-limit test. The editor keeps the same private, portable workflow—one HTML file, no installer, no image uploads, and no changes to your originals.

## Get started

Download **civitai-metadata-studio.zip**, unzip it, and open **civitai-metadata-studio.html** in a current browser. Prefer a single file? Download the standalone HTML instead. Existing users can replace their app copy; no image conversion or migration is needed.

## What improved

- **Safer documentation checks.** Wiki heading anchors now use a single-pass, slug-only scanner instead of regex-based HTML stripping. Quoted attributes, comments, incomplete markup, Unicode, and duplicate headings have dedicated regression coverage. This resolves the wiki checker's CodeQL alert; it is not a change to image metadata parsing.
- **Reliable browser regressions.** The mocked rate-limit response correctly exposes `Retry-After` through CORS. A controlled clock verifies that clearing the public cache does not bypass cooldown, independent of CI runner speed. The application's cooldown behavior is unchanged.
- **Current release guidance.** Download links, checksum records, version reporting, and provenance instructions are refreshed while historical release evidence stays pinned to its original files.

The browser engine changes only its reported version to **1.0.2**. Companion dependencies, the managed SDK repack, Playwright, API operations, identity rules, privacy boundaries, and encoded-pixel preservation are unchanged from 1.0.1. The wiki-checker and test fixes are in GitHub's source archives; the portable ZIP still contains only the browser app.

## Verify your download

The HTML, ZIP, and `SHA256SUMS.txt` receive GitHub/Sigstore build attestations from the release-tag workflow after both platform suites pass. With a current authenticated GitHub CLI:

```powershell
gh attestation verify civitai-metadata-studio.zip --repo chriscollins500/civitai-metadata-studio --signer-workflow chriscollins500/civitai-metadata-studio/.github/workflows/ci.yml --source-ref refs/tags/v1.0.2 --deny-self-hosted-runners
```

Substitute the HTML or checksum filename to verify the other assets. The published release record also supplies the exact source commit and successful workflow run. Attestations authenticate build origin, not malware safety, operating-system publisher trust, or a browser trust badge. [Verification details](https://github.com/chriscollins500/civitai-metadata-studio/blob/v1.0.2/docs/provenance.md).
