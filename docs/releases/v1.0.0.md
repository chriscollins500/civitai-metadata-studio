**Open an AI image. Understand its recipe. Fix the record. Save a clean copy.**

Civitai Metadata Studio is a private, portable metadata editor that runs as a single HTML file. No installer, account, or image uploads. Your originals are never changed.

## Start in 30 seconds

1. Download **civitai-metadata-studio.zip** below.
2. Unzip it and double-click **civitai-metadata-studio.html**.
3. Drop in a PNG, JPEG, WebP, or a whole batch. Review, edit, and save new copies.

Prefer no ZIP? Download the HTML asset directly. Use a current browser; Chrome and Edge were tested on Windows.

## Your image. The whole story.

- **A focused workspace:** edit prompts and generation settings, search resources, undo/redo, and find actions with Ctrl / Command K.
- **Identity without guesswork:** verify exact AIR values, version IDs, and supported hashes against Civitai. Resource names link to their exact Civitai page.
- **Complex-workflow awareness:** follow active ComfyUI branches and exclude disabled or disconnected resources. Conflicting evidence stays visible.
- **Smarter API usage:** batch SHA-256 lookups, reuse cached identities, share in-flight requests, and respect rate-limit cooldowns. No request-per-field behavior.
- **Pixels stay intact:** save a new file in the original format, without re-encoding image or animation payloads. Export integrity checking is on by default.
- **A safer record:** real pixel dimensions initialize editable size fields; unresolved JPEG/WebP resource claims survive saving; changing identity evidence clears stale verification proof.
- **Local-first privacy:** images and prompts stay local. Sensitive camera/location metadata is removed by default, with supported preservation choices available.

## Scripts and assistants welcome

The optional local companion adds an authenticated HTTP API and **14 MCP tools**, sharing the same metadata engine as the editor. Choose its permitted folders and whether it can contact Civitai. Revision checks, atomic edits, cancellation, and new-file-only exports protect your work.

The companion needs Node.js 24+ and the source checkout. It is not required to use the HTML editor. [Setup and API/MCP documentation](https://github.com/chriscollins500/civitai-metadata-studio/blob/v1.0.0/docs/automation.md). A current MCP client supporting protocol 2026-07-28 is required.
